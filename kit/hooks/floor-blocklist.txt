# Floor guard — moves that LOWER the quality bar on the way to a green check (ERE, case-SENSITIVE).
#
# An agent that hits a red check does not invent a clever loophole; it takes the cheapest road to green. That road
# is nearly always one of a handful of shapes, and every one of them is visible in the lines a commit ADDS: a
# checker switched off where it fired, a test made to stop running, a stub or a swallowed error standing where the
# work should be. Tightening the bar needs no gate. Loosening it should be loud. This list is the loud part.
#
# Only ADDED lines in project code are scanned. Documentation (.md .mdx .txt .rst .adoc) is not: a suppression
# written in prose silences nothing. Generated files are not either — a file whose first lines carry a generator
# marker (`<auto-generated`, `Code generated … DO NOT EDIT`, `@generated`) was not written by the author of this
# commit, and EF Core alone puts a warning pragma in every model snapshot it emits (395k such files on GitHub,
# measured), so without that exemption an EF Core project could not commit a migration.
#
# A legitimate exception is a tracked decision, not a loosened rule: `.floor-allowlist.txt` at the repo root, one
# entry per line — `path:<glob>` exempts a path, `rule:<name>` turns one rule off, and any other line exempts the
# EXACT pattern line below. Each entry ends in its reason, `  # <why, 20+ characters>`: an entry without one exempts
# nothing, and a staged allowlist with a bare entry or a reason copied word for word is refused. The allowlist change
# sits in the same diff as the code it excuses, where review sees it; gate-report.sh counts the entries per rule.
#
# `path:` IS A SHELL PATTERN, NOT A .gitignore GLOB, and it is wider than it reads. `*` also matches `/`, so
# `path:*.cs` exempts EVERY C# file in the repository, not the ones at the root; and `**` means nothing special, so
# `path:**/gen/*` exempts `a/gen/x.cs` but not a root-level `gen/x.cs`. Both were measured on Windows 11 and both err
# toward exempting more than the author meant, which is the dangerous direction for an exception. Write the narrowest
# path that names the thing: `path:src/legacy/*`, not `path:*legacy*`.
#
# Each pattern carries its own case below it (`#test:` must be caught, `#test-clean:` must not), and smoke-test.sh
# drives every one through the REAL pre-commit. A `# rule:` line names the rule for the patterns that follow it.
#
# A PATTERN MUST NOT BEGIN WITH `#`. Every loop that reads this file treats such a line as a comment and skips
# it, so `#pragma …` or `# noqa` written plainly is a pattern that looks armed and matches nothing. Write the
# character as a one-member bracket instead — `[#]pragma` is the same ERE and is read as a pattern.
#
# Written for Crewforth:
# bash rather than Node, the staged diff instead of a merge base, per-ecosystem patterns for the stacks Crewforth
# supports, and the generated-file and documentation exemptions that stack needs.
