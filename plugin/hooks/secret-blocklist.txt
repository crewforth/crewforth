# Secret scanner — high-signal patterns (ERE, case-SENSITIVE). One regex per line; '#' starts a comment.
# These match secret VALUES (keys / tokens / private keys), not the word "secret".
# False positive on a real (test) value? Add the EXACT pattern line to .secret-allowlist.txt at the repo root,
# or replace the value with a placeholder. Deliberate bypass: git commit --no-verify (explicit request only, §4.5).
#
# Each pattern carries its own case, on the line right below it:
#   #test:       a sample this pattern MUST catch
#   #test-clean: a sample no pattern may catch
# smoke-test.sh discovers them and drives the REAL hook with them, and it FAILS if a pattern has no case at
# all — an untested regex is how a typo ships as a gate that silently matches nothing. Samples are deliberately
# written with a {{A<n>}} placeholder that the test harness expands to n 'A's at run time. The file therefore
# never contains a contiguous secret-shaped literal — which matters because it ships into every project's
# .claude/, where their scanners would flag it, and because GitHub push protection blocks such a literal on
# sight regardless of how low its entropy is (measured: it rejected the Stripe sample).

# PEM private keys (RSA / EC / OPENSSH / DSA / PGP ...)
-----BEGIN ([A-Z]+ )?PRIVATE KEY-----
#test: -----BEGIN RSA PRIVATE KEY-----
#test: -----BEGIN PRIVATE KEY-----
#test: -----BEGIN ENCRYPTED PRIVATE KEY-----
-----BEGIN PGP PRIVATE KEY BLOCK-----
#test: -----BEGIN PGP PRIVATE KEY BLOCK-----

# AWS access key id
(AKIA|ASIA|AGPA|AIDA|AROA|AIPA|ANPA|ANVA|A3T)[A-Z0-9]{16}
#test: aws_access_key_id = AKI{{A17}}

# GitHub tokens (personal / oauth / user / server / refresh) + fine-grained PAT
gh[pousr]_[A-Za-z0-9]{36,}
#test: token: ghp_{{A36}}
github_pat_[A-Za-z0-9_]{22,}
#test: token: github_pat_{{A24}}

# Google API key
AIza[A-Za-z0-9_-]{35}
#test: key=AIza{{A35}}

# Slack token
xox[baprs]-[A-Za-z0-9-]{10,}
#test: SLACK_TOKEN=xoxb-{{A12}}

xoxe(\.xox[bp])?-[A-Za-z0-9-]{20,}
#test: SLACK_REFRESH=xoxe-1-{{A40}}
xapp-[0-9]-[A-Za-z0-9-]{20,}
#test: SLACK_APP_TOKEN=xapp-1-{{A24}}

# Shopify access, custom-app, private-app tokens and shared secret
shp(at|ca|pa|ss)_[A-Fa-f0-9]{32}

# PyPI upload token (the macaroon always starts the same way)
pypi-AgE[A-Za-z0-9_-]{50,}

# AWS secret access key, recognised by the key that names it: the value alone is 40 characters of base64 with no prefix
(aws_secret_access_key|AWS_SECRET_ACCESS_KEY|SecretAccessKey)[[:space:]"']*[:=][[:space:]"']*[A-Za-z0-9/+]{40}
#test: aws_secret_access_key = {{A40}}
#test: "SecretAccessKey": "{{A40}}"

# A password inside a URL: scheme://user:password@host. A placeholder ($VAR, ${VAR}, <pass>, {{x}}) starts with a
# character the first class excludes, so the ordinary way of writing one about stays committable.
[A-Za-z][A-Za-z0-9+.-]*://[^/[:space:]:@]+:[A-Za-z0-9!#%&*+,.;=?^_|~-][^/[:space:]:@<{}]{5,}@
#test: DATABASE_URL=postgres://app:{{A12}}@db.internal:5432/app
#test: https://deploy:{{A20}}@git.example.com/repo.git

# SendGrid API key
SG\.[A-Za-z0-9_-]{16,32}\.[A-Za-z0-9_-]{16,}
#test: SENDGRID_API_KEY=SG.{{A16}}.{{A20}}

# JSON Web Token (header.payload.signature)
eyJ[A-Za-z0-9_-]{10,}\.eyJ[A-Za-z0-9_-]{6,}\.[A-Za-z0-9_-]{10,}
#test: Authorization: Bearer eyJAAAAAAAAAA.eyJAAAAAA.AAAAAAAAAA

# A credential carried in a URL query. THE CLASS EVERY PATTERN ABOVE STRUCTURALLY CANNOT SEE: all the others
# recognise a credential by its own SHAPE -- AKIA, ghp_, AIza, xox, sk_live_, sk-ant-, npm_, SG., a JWT, a PEM
# header -- and a token with no issuer prefix has no shape to recognise. Measured on a published install with
# the real hook: `http://127.0.0.1:7911/?token=<uuid>`, a bare uuid, and `token=` plus 32 hex all committed
# cleanly while the calibration lines beside them were caught, so this was a hole rather than a guess.
# Crewforth produces exactly such a URL itself -- the Studio panel mints one per run and the command hands it to
# the user -- but the pattern is deliberately about the QUERY KEY, not about that panel: any `?token=` long
# enough to be real is one, whoever minted it.
# Anchored on the key and a 20-character floor so the ordinary ways of WRITING one about stay committable:
# `?token=<your-token>` and `?token=$VAR` carry characters the class excludes, so the run measures zero.
[?&](token|api_?key|apikey|access_token|auth_token)=[A-Za-z0-9._~-]{20,}
#test: curl https://api.example.com/v1/items?token={{A20}}
#test: https://127.0.0.1:7777/?token={{A32}}
#
# The other half of the same leak is NOT closable here and is left to `.private-terms.txt` on purpose: a machine
# name is any word, so no pattern can tell one from prose. That half stays model discipline, and /crew-studio
# says so where it tells the model what may be quoted.
